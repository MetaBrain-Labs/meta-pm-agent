# Toolkit Executor

## 概述

Toolkit Executor（工具集执行器）是产品设计知识图谱系统中负责辅助性、合规类任务的 Agent。它处理不直接参与产品设计主因果链的辅助工作——隐私合规、法律文件、文档质量审视和人才评估。大部分技能创建 `自定义` 或 `组件` 实体，不参与 `目标→需求→决策→功能→组件` 主溯源链。

## 目录结构

```
toolkit-executor/
├── executor.json              # Executor 配置文件
├── README.md                  # 本文件
├── prompts/
│   ├── system_prompt_cn.md    # 中文系统提示词
│   └── system_prompt_en.md    # English system prompt
└── skills/                    # 4 个内建技能（2 类）
    ├── privacy-policy/        # 合规类
    ├── draft-nda/             #   同上
    ├── grammar-check/         # 审视类
    └── review-resume/         #   同上
```

## 技能列表

### 合规类

| 技能 | 创建实体 | 主要关系 | 参与主链路 |
|------|---------|---------|:---:|
| privacy-policy | 组件 | 限制 | 是 |
| draft-nda | 自定义: 法律文件 | 自定义 | 否 |

### 审视类

| 技能 | 操作类型 | 创建实体 | 参与主链路 |
|------|---------|---------|:---:|
| grammar-check | 修改已有节点描述 | — | 否 |
| review-resume | 创建 | 自定义: 人才评估 | 否 |

## 与知识图谱的关系

与其他 Executor 不同，本 Executor 的大多数产出不参与产品设计主溯源链（`目标→需求→决策→功能→组件`）：

```
主链路外：
  自定义: 法律文件  ──自定义──→ 项目上下文
  自定义: 人才评估  （孤立节点）

主链路内（仅 privacy-policy）：
  功能 ──限制──→ 组件: 隐私策略约束
```
