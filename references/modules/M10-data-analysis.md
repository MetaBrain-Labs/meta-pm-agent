# M10 数据验证

## 模块定位

把目标指标落成可采集、可计算的验证方案，并以用户视角自检产品逻辑是否自洽。回答上线后靠什么数据判断产品有效。

## 内容结构

埋点采集：采集什么数据、在哪些环节采集。

指标计算口径：每个指标如何计算，口径清晰唯一。

验证方案：上线后如何判断各指标是否达成。

产品逻辑自检：以用户视角走核心流程，对照功能层级与产品方案，检查逻辑是否自洽、是否走得通，仅基于现有文档修补。

## 填写要求

- 埋点覆盖 M04 的目标指标。
- 计算口径清晰，避免含糊。
- 自检反复进行，直到逻辑完整。

## 质检要点

- 指标计算口径是否唯一明确。
- 埋点是否覆盖全部目标指标。
- 自检发现的逻辑缺口是否已修补。
