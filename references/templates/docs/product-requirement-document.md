# 产品需求文档标题
+ 文档基础信息
+ 文档目录

## 文档概述
主要说明背景概述、范围和边界、术语定义。

背景概述：描述整个项目的初始需求背景，目的是让未参与过项目的人能通过背景概述了解该项目。

范围和边界：描述项目的影响规模，包括产品边界、业务边界、运营边界、技术和人力资源边界等。

术语定义：介绍文档中可能出现的专业术语，确保所有术语都有唯一的注解。

## 产品说明
主要说明产品简介和产品流程。

产品简介：作为背景概述的补充，用于介绍产品的基本情况，包括产品定位、用户使用场景以及产品的功能介绍等。

产品流程：描述核心功能的业务流图以及操作流程图，以方便阅读者快速了解产品的核心流程。

## 功能需求
用于向研发人员说明产品的实现逻辑。针对每一条功能描述：功能简介、场景描述、前置条件、需求描述、后置条件、补充说明。

功能简介：对功能做简洁的描述。

场景描述：描述功能的使用场景。

前置条件：描述功能操作索要的前置条件。

需求描述：对整个功能需求的的详细描述。

后置条件：描述功能操作后将产生的结果

补充说明：对需求补充其他解释说明。

## 非功能需求
对功能需求的辅助和补充，非功能需求常包括：技术需求、运营需求、财务法务需求、其他需求等。
