# 资料调研指南(research-guide)
本文档说明如何在 skill 执行过程中进行资料调研。需要补充信息、验证判断、扩展认知时，引用本指南。

## 资料来源
调研资料主要来自三个来源：

**用户输入**：用户在对话中提供的资料、判断、数据。

+ 包括用户上传的文件、回答中提到的事实、用户的行业经验。
+ 这类资料的可信度由用户负责,Claude 接受但需要在产出中标注。

**联网搜索**：通过 Agent 提供的搜索工具获取的实时信息。

+ 仅在 Agent 提供搜索能力时可用。
+ 这类资料的可信度由来源质量决定,需要标注具体来源(机构、报告、时间)。

**已有知识**：大模型训练数据中的内容。

+ 永远可用,但有时效性差异。
+ 稳定事实(行业格局、典型模式、历史事件)可用；时效数据(市场规模、用户数、近期动态)不可用，列入待调研项。

每条调研结论必须能追溯到这三个来源中的一个或多个。混合使用时，显式说明来源构成。

## 调研原则
### 主动而非被动
调研自动执行，不需要每次问用户“要不要调研”。根据以下条件自主判断:

+ 哪些信息需要补充？
+ 信息来源是否缺失？
+ 哪些资料需要验证？

调研开始时简要告诉用户调研范围，完成后告诉用户调研结果和信息缺口，让用户判断是否需要调整方向。

### 用户提供资料优先
用户输入的资料、判断、行业经验，优先级高于联网搜索和已有知识。

但用户输入和搜索结果冲突时，不要默认采信任何一方，明确告诉用户冲突点并询问：

> 你提到 X，但我搜索到的近期信息显示 Y。两者可能因为 [可能原因] 而不同；  
你倾向以哪个为准?或者需要更深入查证？
>

### 时效信息使用联网搜索
如果 Agent 有联网搜索能力，则所有涉及具体数据、近期事件、当前状态的内容都通过搜索获取，不依赖已有知识。

已有知识可以用于：

+ 背景判断(这个行业大致什么样)
+ 关键词扩展(知道该搜什么)
+ 结果筛选(搜索结果是否符合常识)

但不能用于：

+ 直接给出具体数字
+ 给出"我记得是..."这种凭印象的判断
+ 推断"近期情况"

### 不具备联网能力时
如果 Agent 没有联网搜索能力，则所有时效性强的信息处理方式为：

+ 不要使用已有知识中的过期数据填充
+ 不要编造或推测
+ 列入待调研清单,在产出中显式标注"需要用户实际调研"

具体的待调研清单格式见下文。

## 调研深度
自由决定"必须搜几条"、"必须验证几次"。

调研是否继续深入的判断标准是"读者能不能基于调研内容做决策"，由用户在迭代过程中判断。一份给天使轮投资人的 BRD 和一份给上市公司战略部的 BRD，需要的调研深度差几个数量级。让用户在迭代中告诉你"够了"或"还要深入"。

## 待调研清单
如果出现"应该调研但本次无法完成"的项，必须在产出末尾附"待调研清单"，列出：

+ 调研目标(要验证什么)
+ 建议方法(查什么报告、问哪类人、用什么工具)
+ 优先级(决策性的 vs. 补充性的)

产生待调研清单的可能场景：

1. Agent 无联网能力，所有时效信息都列入清单。
2. Agent 有联网能力但搜索失败，搜不到的项列入清单。
3. 某些信息必须通过实际访谈、内部资料、专业咨询才能获得，联网搜索也无法解决。

示例:

> 待调研清单:
>
> 1. 目标市场近 12 个月规模和增长率
>     - 方法：查询艾瑞咨询、易观、Gartner 等机构最新行业报告
>     - 优先级：高(直接影响投资决策)
> 2. 目标用户当前实际付费意愿
>     - 方法：对 20-30 个目标用户做付费意愿访谈
>     - 优先级：高(无法通过联网搜索获得,必须实际访谈)
>

把调研缺失转化为用户可执行的下一步动作。比假装做了调研更有用。

## 搜索原则
### 信息选择
+ 优先使用近 1-2 年的来源，过期信息只用于背景参考。
+ 对每条关键数据标注来源(机构、报告名称、发布时间)，不笼统说"据调研"。
+ 多源验证关键数据,单一来源的数字标注"待验证"。
+ 不为了"看起来全面"引入大量低质量来源，3-5 个高质量来源胜过 20 个低质量结果。
+ 中文场景调研可用百度、知乎、行业垂直媒体；海外调研用 Google、专业数据库。

### 搜索失败时
如果搜索不到信息，不要编造，明确告知用户：

> 本次调研未找到 X 的可靠数据。可能的原因：[行业太新 / 数据未公开 / 关键词不够准确]。  
你有什么内部信息或行业人脉可以补充吗？如果没有，这部分会列入待调研清单。
>

搜索失败本身是有价值的信息，告诉用户这块需要额外的人工或专业资源去补。

## 资料标注规则
任何阶段的产出文档中，涉及调研结果的内容必须标注来源类型。

标注方式：

**【用户提供】**：基于用户提供的资料  
**【联网调研】**：基于联网搜索结果(同时标注具体来源,如机构、报告名)  
**【模型知识】**：基于训练数据中的稳定事实(同时标注时效边界)

混合来源时，标注主要来源并说明：

> 目标市场 SaaS 协同办公行业,【已有知识】整体处于成熟期，  
【调研:艾瑞 2025 年报告】2024 年市场规模约 X 亿元,年增长率 Y%，  
【用户输入】用户判断目标细分市场占整体的 20% 左右。
>

确保读者能清晰区分每条结论的来源和可信度。
